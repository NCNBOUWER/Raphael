## Handshake policy
The route planner is a **candidate analysis provider** only. Publishing a schema record does not install a connector, update physical machine configuration, grant production authority, or make synthetic test values valid for physical operations. Use the logical `cgx://romer.industries/emassc/printspace` namespace as a proposed namespace, not an asserted resolver mapping.

Input: functional contract + qualified feedstock/material passports + interfaces/topology + machine envelope + exact process route + measured exposure histories + operator authority.
Output: directional process transitions, multi-stage ordering, unresolved exposures, cumulative survival flags, proposed measurements, and a `production_approved=false` candidate report.

### Promotion gates
- Gate 0: owner approves vocabulary and reconciles existing source IDs/lineage (no parallel authority).
- Gate 1: exact materials/lots, interface shapes, atmosphere, temperature/pressure/field windows and output acceptance criteria captured with SI units and uncertainties.
- Gate 2: measured coupon and subassembly data per specific process sequence; include bidirectional and non-adjacent route effects.
- Gate 3: full route verifies seals, storage, transfer, thermal/chemical history, contamination, electrical and mechanical tolerance, ageing, common-mode risks and reversibility.
- Gate 4: machine tooling and operator control reviewed separately from process capability; human-approved physical instruction and independent fail-safe.
- Gate 5: lifetime monitoring, repair and recovery records integrated with data lineage.

## Scheduler development order
1. Preserve directional P/S/T/M/R pair metadata and instrument route-specific substitutions without reclassifying untested material pairs as physically qualified.
2. Attach verified physical properties from Raphael/material passports via stable IDs, never by guessed material name.
3. Extend scalar synthetic exposure tests to spatial histories and calibrated constitutive models (T(x,t), chemical activity, fields, strain, gradients, environmental shifts).
4. Compare routes under equal acceptance criteria: co-print → sequential → staged atmosphere/interface → module → R&D route.
5. Incorporate multi-object layout, chamber transition overhead, printable spare volume, energy, time, cost and circular-lifecycle utility only after safety and feasibility.
6. Map qualified processes to actual PrintSpace cells, micro-scale specialists and gravity-specific stations without pretending one printhead performs every process.

## Safeguards
A seal is not considered hermetic merely because it is closed. In the synthetic sample, gate names are planned-stage labels; production consumption must instead demand observed, timestamped evidence linked to calibration, instrument IDs and immutable receipts. Absence of exposure data cannot be inferred as zero exposure.
