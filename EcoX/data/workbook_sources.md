# Eco-X Workbook Source Map

**Workbook artifact:** `EcoX_Preliminary_Control_Workbook.xlsx`  
**Runtime output:** `/mnt/data/EcoX_Preliminary_Control_Workbook.xlsx`  
**Status:** created as preliminary update-control workbook. GitHub connector currently supports UTF-8 text file writes only, so the binary `.xlsx` should be uploaded to the dedicated Eco-X repo or Drive after manual review.

## Sheets

| Sheet | Function |
|---|---|
| Dashboard | Timestamp, status, KPI counts and review gate. |
| Document_Register | Tracks business plan, dossiers, Canva status and next actions. |
| Application_Matrix | Maps scale, use case, Embedded role, Second Cycle role, Brown Waste role, revenue/funding logic and evidence gate. |
| Roadmap | Phase-led research/application timeline from current public stage to interplanetary adaptation. |
| Funding_Model | Economic model for perpetuity, including paid packages, buy-a-block, contracts, grants, philanthropy and qualified carbon/biodiversity pathways. |
| Risk_FMEA | Preliminary risk rows with severity, occurrence, detection and RPN formulas. |
| MRV_Metrics | Monitoring, reporting and verification metrics. |
| Source_Map | Official reference sources and public page anchors. |
| Canva_Publish_Workflow | GitHub → workbook → Canva → manual review → Google Drive publishing workflow. |

## Update rule

Future `.xlsx` revisions should be generated from this source suite, then backported into GitHub as updated Markdown/CSV plus binary `.xlsx` once the dedicated Eco-X repo is available.
