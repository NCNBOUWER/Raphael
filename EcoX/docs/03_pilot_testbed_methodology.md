# Eco-X Pilot, Testbed & Methodology Dossier

## Purpose

This dossier sets the method for moving Eco-X from concept to measured deployment.

## Standard deployment pathway

1. Intake.
2. Site classification.
3. Baseline assessment.
4. Stack design.
5. FMEA.
6. Pilot deployment.
7. MRV monitoring.
8. Local training.
9. Review.
10. Scale, hold or stop.

## Pilot classes

| Class | Examples | Primary test |
|---|---|---|
| Garden | Home/private biodiversity | Survival, soil moisture, food/habitat function |
| School/community | Training gardens, brown-waste loops | Capability transfer and continuity |
| Agriculture | Field edge, dam edge, shelterbelt | Soil/water/biodiversity response |
| Wildfire/disaster | Erosion, revegetation, water retention | Stabilisation and establishment |
| Urban/city soaking | Stormwater, heat, corridors | Capture, cooling, runoff, maintenance |
| Humanitarian | Post-war/poverty contexts | Food-water stability and local training |
| InterSol | Active management site | Integrated ecological envelope proof |
| Moon/Mars research | Closed-loop prototypes | Biosphere/water/substrate logic |

## FMEA model

Each deployment must score:

- wrong species / invasive risk;
- unsafe water source;
- contaminated substrate;
- maintenance failure;
- local governance failure;
- safeguarding failure;
- public claim overreach;
- carbon/biodiversity qualification risk;
- operational boundary confusion.

## MRV metrics

- Plant survival.
- Soil moisture.
- Water captured/retained.
- Organic matter/soil carbon proxy.
- Food yield.
- Biodiversity observations.
- Training completion.
- Maintenance burden.
- Community continuity.
- Cost per functioning deployment.

## Scale rule

Scale only after measured performance, local capability, acceptable maintenance burden, review approval and impact evidence.
