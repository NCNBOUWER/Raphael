## Purpose

Eco-X is the ecological operating and public-benefit pathway for Eco-Grex, Embedded and Second Cycle. The system is designed to:

- define ecological functions before candidate species or technical components;
- protect intact systems and retain non-intervention as a valid decision;
- represent affected human, non-human, ecological, cultural and future-generation interests;
- create controlled test beds, evidence rooms, FMEA and MRV;
- coordinate place-specific deployment without erasing local authority or viable livelihoods;
- separate reported, measured, derived, reasoned, modelled and aspirational claims.

## Projection boundary

The projection engine produces **normalised contribution indices** from explicit project inputs: deployment year, ramp, duration, scale, project state, confidence, governance and application variant. These outputs support comparison and planning. They are not direct forecasts of hectares restored, pollutant loads removed, species populations, carbon credits, river condition or reef condition until calibrated with measured project and receiving-system data.

## Application logic

### Embedded

Land-restoration application family covering substrate, soil, seed/spore, habitat, corridor, brown-waste and rehabilitation modules. Candidate biological components remain place-specific and review-gated.

### Second Cycle

Water-cycle application family covering capture, separation, filtration, storage, reuse, controlled soaking, safe overflow and monitoring. Second Cycle is not weather control.

### Eco-Grex

Integrated configuration layer combining Embedded, Second Cycle, community capability, governance and evidence functions. Stacked benefits, overlap, maintenance and residual risk are modelled separately.
